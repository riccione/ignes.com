## Key Features

* Converts between all major e-book formats (EPUB, MOBI, AZW3, PDF, etc.).
* Fetches metadata and covers from the internet automatically.
* Built-in content server for browser-based library access.
* Connects to Kindle, Kobo, Nook, and other e-readers.
