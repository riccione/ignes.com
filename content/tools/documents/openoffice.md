## Key Features

* Six integrated applications: Writer, Calc, Impress, Draw, Base, and Math.
* Native OASIS OpenDocument Format (ISO/IEC 26300) with Microsoft Office file compatibility.
* Free to download, use, and distribute under Apache-2.0.
* Available in 41 languages for Windows, macOS, and Linux.
* Extensions and templates ecosystem, with Python macro editing in 4.1.17.

## Project Status

Apache OpenOffice is maintained but conservative: the 4.1.x line is in maintenance mode with a slow release cadence, while development targets version 5.0 with native Windows 64-bit and Apple Silicon support.
