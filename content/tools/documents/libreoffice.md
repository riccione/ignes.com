# LibreOffice

{{< tool-info >}}

## Key Features

* Six integrated apps: Writer (word processing), Calc (spreadsheets), Impress (presentations), Draw (vector graphics), Base (databases), and Math (formulas).
* High compatibility with Microsoft Office formats (.docx, .xlsx, .pptx) and ODF standard.
* Extensive language support (167+ languages) and cross-platform availability.
* Extension and template ecosystem for customization and additional functionality.
* Built-in PDF export, EPUB export, and Markdown support.
