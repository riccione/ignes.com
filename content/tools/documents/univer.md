## Key Features

* One runtime for spreadsheets, docs, slides, canvas, relational tables, and PDF.
* Plugin-first architecture with a unified Facade API for browser and Node.js.
* Canvas-based rendering and formula engine with 500+ built-in functions.
* Isomorphic by design — React, Vue, and Web Components supported.
* Self-hosted, embeddable, and white-label with no watermark.

## Licensing

Univer's community edition is fully open source under Apache-2.0. Some advanced features — real-time collaboration, import/export, charts, and pivot tables — are only available in the commercial Pro edition.
