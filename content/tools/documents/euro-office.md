## Key Features

* Real-time collaborative web editors for documents, spreadsheets, presentations, and PDFs.
* High compatibility with Microsoft OOXML (DOCX, XLSX, PPTX), ODF, PDF, and more.
* Self-hostable Document Server with REST API, Docker/deb/rpm packaging, and Nextcloud integration.
* Native desktop editors for Windows, macOS, and Linux with offline editing.
* 46 interface languages, RTL support, dark mode, and plugins.

## Project Status

Euro-Office is a fork of ONLYOFFICE DocumentServer, governed independently by a European coalition including Nextcloud, IONOS, XWiki, and Proton. It launched publicly in March 2026 and is very actively developed.
