## Key Features

* Self-hosted metasearch engine aggregating results from up to 261 search services.
* No user tracking or profiling; JavaScript and cookies are optional.
* Available in 58 translations, with about 70 well-maintained public instances.
* Can be used over Tor for anonymity and integrated as a browser search engine.
* Easy to extend with new search engines and data sources.

## Notes

SearXNG follows a rolling release model pulled from the master branch rather than tagged versions.
