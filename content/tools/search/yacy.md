## Key Features

* Full search-engine application with an index server, web front-end, and production-ready crawler.
* Peer-to-peer search network where peers exchange search indexes.
* Intranet search appliance that discovers HTTP, FTP, and SMB servers.
* Privacy-focused options for local-index-only mode and opting out of the P2P network.
* HTTP/XML and HTTP/JSON APIs for embedding search in other applications.
