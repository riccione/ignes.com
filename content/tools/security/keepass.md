## Key Features

* AES-256, ChaCha20, and Twofish encryption with multiple key providers.
* Portable mode — can run from a USB stick without installation.
* Auto-Type feature that fills credentials into applications and websites.
* Extensible plugin architecture with a large library of community plugins.
