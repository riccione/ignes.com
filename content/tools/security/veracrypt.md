## Key Features

* Full-disk encryption including the Windows system partition with pre-boot authentication.
* Hidden volumes and hidden operating system for plausible deniability.
* Supports AES, Serpent, Twofish, Camellia, and cascaded combinations.
* Hardware-accelerated encryption with near-native read/write speeds.
