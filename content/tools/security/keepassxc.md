## Key Features

* AES-256 / ChaCha20 encryption with Argon2id key derivation.
* Browser integration for Chrome, Firefox, Edge, Brave, and more.
* Built-in TOTP storage and generation, plus YubiKey support.
* SSH Agent integration and FreeDesktop.org Secret Service support.
