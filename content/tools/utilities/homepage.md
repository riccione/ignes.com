## Key Features

* Fast page loads with cached dashboard data and optimized assets.
* All API requests to backend services are proxied, keeping API keys hidden.
* Over 100 service integrations, plus Docker container status and label-based discovery.
* YAML configuration with custom themes, CSS, and layouts.
* Full internationalization with support for over 40 languages.

## Scope

Homepage is an application dashboard and start page rather than a monitoring engine. It includes a resource widget but does not collect metrics on its own.
