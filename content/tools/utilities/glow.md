## Key Features

* Beautiful terminal rendering of markdown with styled themes.
* TUI file browser for discovering and navigating markdown files.
* CLI mode: render from file, stdin, URLs, or GitHub/GitLab links directly.
* Configurable word wrapping, paging, and line number display.
