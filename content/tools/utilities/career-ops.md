## Key Features

* Evaluates each job posting against your CV with per-requirement weighting and a 1-5 match score.
* Scans 150+ job sources and verifies posting liveness before you spend time applying.
* Generates ATS-friendly CVs and research-backed cover letters tailored to each job description.
* Human-in-the-loop application flow — fills forms field by field and stops before Submit.
* Markdown/YAML pipeline tracker with a terminal dashboard, follow-up mode, and rejection analysis.

## Requirements

career-ops runs locally inside an AI coding CLI such as Claude Code, Codex, or OpenCode. It requires Node.js 22.13+ and git. The local web UI is experimental, and the hosted web version is not yet available.
