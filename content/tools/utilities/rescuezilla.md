## Key Features

* Simple graphical environment that boots from USB in seconds — no installation needed.
* Backup images fully interoperable with Clonezilla in both directions.
* Supports VM images: VirtualBox (VDI), VMware (VMDK), Hyper-V (VHDx), QEMU (QCOW2), raw (.dd, .img).
* Saves and restores Windows, Mac, and Linux machines from any PC or Mac.
* Image Explorer to mount images and copy files, plus partition editor and file undelete.
