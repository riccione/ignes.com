## Key Features

* Glassmorphic design with dynamic backgrounds and smooth animations.
* Written in React and Node.js with a focus on responsiveness, even on low-end hardware.
* Privacy first — data never leaves your machine and it works fully offline.
* Widgets for OS, CPU, storage, RAM, network, and optional GPU monitoring.
* REST API and embeddable iframe widget, with prebuilt integrations for dashboards.

## Project Status

Dashdot is stable and maintained, but feature development has slowed: recent activity consists mainly of dependency updates.
