## Key Features

* Per-second metric collection and processing with one-second visualization latency.
* Zero-configuration auto-discovery of systems, containers, VMs, and applications.
* Edge-based, unsupervised machine learning anomaly detection per metric.
* Efficient long-term retention with tiered time-series storage.
* Auto-generated interactive dashboards with no query language required.

## Licensing

Netdata is open-core. The Netdata Agent is open source under GPL-3.0, while the default dashboard UI and the optional Netdata Cloud service are proprietary. The mobile apps are also proprietary.
