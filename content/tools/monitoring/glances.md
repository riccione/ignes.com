## Key Features

* Real-time monitoring of CPU, memory, load, disks, network, sensors, GPUs, and processes.
* Terminal interface and a built-in web UI for the same data.
* Client/server remote monitoring through a web interface or RESTful API.
* Container and VM monitoring for Docker, Podman, LXD, Multipass, and libvirt.
* Exports and integrations for InfluxDB, Prometheus, Graphite, Elasticsearch, Kafka, and more.
