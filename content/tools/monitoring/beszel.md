## Key Features

* Lightweight hub-and-agent design, smaller and less resource-intensive than leading solutions.
* Per-container CPU, memory, and network usage history for Docker and Podman.
* Alerts for most metrics with Slack, Discord, Telegram, ntfy, and webhook notifications.
* Network monitoring with ICMP, TCP, HTTP, and DNS probes from agents.
* S.M.A.R.T. disk health and GPU monitoring, plus multi-user, OAuth, and REST API access.
