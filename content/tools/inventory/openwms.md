## Key Features

* Warehouse Management (WMS) plus Warehouse Control and Transport domains.
* Microservices and cloud-native architecture following the Twelve-Factor manifesto.
* ERP integration and field-controller connectivity (PLC, Raspberry Pi).
* Workflow engine for dynamic material-flow control.
* COP operator web application and Roma mobile handheld app.

## Project Status

OpenWMS is a niche, integration-heavy enterprise project with a slower release cadence than the inventory tools listed above.
