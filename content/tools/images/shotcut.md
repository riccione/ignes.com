## Key Features

* Native timeline editing with no import required, supporting hundreds of audio/video formats.
* Blackmagic Design SDI/HDMI support for input and preview monitoring with up to 4K resolution.
* Sleek, intuitive interface with multiple dockable/undockable panels.
* Comprehensive video filters including color grading, compositing, and audio processing.
