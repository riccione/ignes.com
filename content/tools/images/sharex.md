## Key Features

* Multiple capture methods: fullscreen, region, active window, scrolling capture, and screen/GIF recording.
* Built-in image editor with annotation tools (blur, pixelate, text, shapes, smart eraser).
* Upload automation to 80+ destinations (Imgur, Google Drive, Dropbox, custom uploaders).
* OCR text recognition, QR code scanning, and color picker.
