## Key Features

* Three toolsets — pixel art, painting, and vector — all usable on one canvas.
* Frame-by-frame animations with a timeline.
* Node render system — layers, effects, and shaders exposed as a node graph.
* Dedicated pixel art toolset with pixel-perfect pen mode and palette management.
* Desktop native, cross-platform, works offline.
