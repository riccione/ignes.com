# GIMP

{{< tool-info >}}

## Key Features

* Non-destructive layer effects, link layers (similar to Smart Objects), and vector layers.
* Extensive painting tools with customizable brushes, patterns, and gradients.
* Support for numerous file formats including PSD, TIFF, PNG, JPEG, HEIF, and more.
* Highly customizable interface with single-window and multi-window modes.
* Scriptable via Script-Fu, Python-Fu, and a wide range of third-party plugins.
