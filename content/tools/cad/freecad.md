## Key Features

* Parametric 3D solid modeling with constraint-based sketches.
* Dedicated workbenches: Part Design, BIM, CAM/CNC, and FEM analysis.
* Reads/writes open formats: STEP, IGES, STL, SVG, DXF, OBJ, IFC, DAE.
* Full Python scripting API and C++ extension framework.
