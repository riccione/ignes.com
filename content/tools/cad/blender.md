## Key Features

* Jaw-dropping renders with Cycles, the high-end production path tracer.
* Extensive modeling toolset — sculpting, retopology, modeling, and curves.
* Powerful simulation tools built on industry-standard libraries like Bullet and MantaFlow.
* Camera and object motion tracking, masking, and compositing to fix it in post.
* Extensive Python API — every tool available for scripting and customization.
