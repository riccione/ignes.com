## Key Features

* Clean, LLM-ready Markdown generation with headings, tables, code blocks, and citations.
* Structured data extraction using CSS/XPath schemas or any LLM provider.
* Asynchronous browser control via Playwright with sessions, proxies, and stealth mode.
* Deep crawling with BFS, DFS, and best-first strategies, plus adaptive crawling.
* Self-hosting via Docker REST API and CLI, with caching, hooks, and high concurrency.

## Project Status

Crawl4AI is pre-1.0 and releases rapidly, so APIs may change. Its license is Apache-2.0 with an additional attribution requirement.
