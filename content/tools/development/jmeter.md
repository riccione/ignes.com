## Key Features

* Tests HTTP/HTTPS, SOAP/REST, FTP, JDBC, LDAP, JMS, mail, TCP, and more.
* Full-featured Test IDE for recording, building, and debugging test plans.
* CLI (headless) mode to load test from any Java-compatible OS.
* Ready-to-present dynamic HTML reports.
* Complete portability with 100% Java purity and a highly extensible, pluggable core.
