## Key Features

* Daemonless, rootless container execution by default.
* Near drop-in Docker CLI replacement (alias docker=podman).
* Native Kubernetes integration (play/generate Kubernetes YAML).
* Podman Desktop GUI for visual container, image, and pod management.
