## Key Features

* Configurable load generation — even lower-end machines can simulate lots of traffic.
* Tests as code — reuse scripts, modularize logic, version control, and integrate with your CI.
* A full-featured scripting API that simulates real application traffic.
* Embedded JavaScript engine — the performance of Go with the familiarity of JavaScript.
* Multiple protocol support — HTTP, WebSockets, gRPC, browser, and more.
