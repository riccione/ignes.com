## Key Features

* Single interface for HTTP and headless browser crawling.
* Persistent request queue with breadth-first and depth-first crawling.
* Pluggable storage for tabular data and files.
* Automatic scaling with available system resources.
* Integrated proxy rotation, session management, hooks, retries, a CLI, and Dockerfiles.

## Project Status

Crawlee is made by Apify, which also runs a paid cloud platform; the library is complementary to it rather than a replacement.
