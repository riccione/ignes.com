## Key Features

* High-level crawling and scraping framework for Python 3.11+.
* CSS and XPath selectors plus an interactive shell for testing them.
* Asynchronous engine with pluggable scheduler, downloader, middlewares, and item pipelines.
* Built-in feed exports (JSON, CSV, S3) and a large extension ecosystem.
* robots.txt handling, throttling, cookies and sessions, and production deployment options.
