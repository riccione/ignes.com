## Key Features

* Clean API for writing crawlers, scrapers, and spiders.
* Fast — over 1,000 requests per second on a single core.
* Manages request delays and maximum concurrency per domain.
* Automatic cookie and session handling with sync, async, and parallel scraping.
* Caching, robots.txt support, distributed scraping, and extensions.

## Project Status

Colly is stable and widely used with infrequent tagged releases, though development continues through regular commits.
