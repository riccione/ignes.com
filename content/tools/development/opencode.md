## Key Features

* Model-agnostic: supports 75+ LLM providers including local models via Ollama.
* LSP-enabled: automatically loads the right language servers for the LLM context.
* Multi-session: run multiple agents in parallel on the same project.
* Built-in agents: "build" (full-access) and "plan" (read-only analysis) modes.
