## Key Features

* Project-based workflow where project data flows down to all level files from one window.
* Powerful layer types: tile, decal, entity, and grid.
* Engine-agnostic JSON output that is easy to parse and integrate.
* Free for personal and commercial projects under the MIT license.
* Cross-platform desktop app written in Haxe and Electron.

## Project Status

Ogmo Editor 3 CE is the community edition of a discontinued tool. It is stable and still widely used, but there has been no release since 2020 and no substantive commit since early 2022.
