## Key Features

* Layered map editing with tile, image, object, and group layers, plus brush sizes and shape tools.
* Autotile and terrain tooling with standard, diagonal, sparse, and Wang tile presets.
* Built-in pixel image editor with palette import from GIMP, Adobe ASE, Aseprite, and Paint.NET.
* AI-assisted asset drafting through your own provider API keys.
* Import and export for Tiled maps, Godot 4, Unity, GameMaker, Defold, Phaser, and common image formats.

## Project Status

2DTiler is an early alpha project that is browser-only and has seen little activity since May 2026, so treat it as experimental.
