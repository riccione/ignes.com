## Key Features

* Flexible object layers with rectangles, points, ellipses, polygons, and tile objects.
* Efficient tile editing with multiple layers, terrain brush, rule-based Automapping, and stamps.
* Large worlds through infinite maps and multiple maps organized into world files.
* Orthogonal, isometric, staggered, hexagonal, and oblique projections.
* TMX/TSX format plus JSON, Lua, GameMaker, Defold, and other exports, with JavaScript scripting for custom formats.

## Licensing

The Tiled editor is GPL-2.0, while the bundled libtiled library is BSD-2-Clause. Tiled is not a sprite or tileset image generator, though it manages tileset metadata.
