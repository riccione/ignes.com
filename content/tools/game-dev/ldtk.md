## Key Features

* Worlds with Grid-vania, linear, or free layouts and drag-and-drop level organization.
* Auto-rendering and auto-layers with a visual rule editor for automatic tile skinning.
* Customizable entities with arbitrary typed properties such as hit points, patrol paths, and triggers.
* Loads Aseprite files directly with live reloading and automatic resizing.
* Simple and full JSON export, optional Tiled export, and importers for Unity, Godot, Haxe, GameMaker, and more.

## Project Status

LDtk is mature and widely used, but releases are infrequent: the latest stable version dates from January 2024, with a newer build offered only as an unsigned preview.
