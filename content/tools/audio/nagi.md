## Key Features

* Folder-based library with automatic rescanning and wide format support.
* Playlists, rule-based smart playlists, favorites, and listening history.
* 10-band EQ, ReplayGain, pitch-preserving speed control, and sleep timer.
* Synced lyrics from embedded tags, LRC files, and online sources.
* Windows integration — tray popup, media keys, system media controls, and mini-player.
