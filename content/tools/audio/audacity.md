## Key Features

* Multi-track audio editing with sample-level precision and unlimited undo/redo.
* Plugin support for VST3, LV2, AU, and Nyquist scripting.
* Import/export of major audio formats (WAV, MP3, FLAC, OGG, and more via FFmpeg).
* Real-time effects, noise reduction, and deep audio analysis via Spectrogram view.
* Batch processing via macros and scripting in Python, Perl, or any language supporting named pipes.
