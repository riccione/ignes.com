## Key Features

* Dynamic playlists that match different criteria.
* Collection management with ratings and a cover manager.
* Basic iPod, MTP, and UMS music-player device support.
* Last.fm, Magnatune, and Ampache integration, plus scripting support.

## Project Status

Amarok is an older project that is still maintained, though its release cadence is slower than newer players.
