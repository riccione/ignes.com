## Key Features

* Music library with multiple playlists.
* Internet radio streams and podcasts, plus network shares.
* Portable music devices, including phones.
* Last.fm and Magnatune integration, with an extensible plugin system.

## Project Status

Rhythmbox is a long-standing GNOME application that remains actively maintained, with regular releases.
