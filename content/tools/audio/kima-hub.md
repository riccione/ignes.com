## Key Features

* Point it at a folder of music and stream it from any browser, with a TV-friendly layout.
* "Vibe engine" using CLAP embeddings for similarity matching, a 3D map, and mood mixes.
* Podcasts with cross-device resume, plus Audiobookshelf integration for audiobooks.
* Multi-user accounts with 2FA, OpenSubsonic API compatibility, and ListenBrainz scrobbling.

## Notes

Kima Hub is a self-hosted server, not a local desktop player, and the full similarity features need substantial hardware. One bundled data file is licensed CC BY-NC.
