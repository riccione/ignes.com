## Key Features

* Self-contained player with a bundled MPD, or connect to an existing MPD server.
* Bit-perfect playback including direct DSD/DoP.
* Customisable spectrum visualizer via MPD FIFO or PipeWire.
* Advanced client-side dynamic playlists with query and sticker rules.
* GTK4/libadwaita interface with album-art accent colors and MPRIS integration.

## Project Status

Euphonica is still pre-1.0 beta software, actively developed but with occasional rough edges.
