## Key Features

* Project tree with drag-and-drop chapters, scenes, folders, and sub-documents.
* Novel View and Outline View for structural overview and metadata.
* Meta keyword/value tags for comments, synopsis, and cross-references between files.
* Build Manuscript export to OpenDocument, Word, PDF, HTML, and Markdown.
* Focus Mode, parallel document viewer, and configurable color and syntax themes.
