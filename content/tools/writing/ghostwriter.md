## Key Features

* Distraction-free fullscreen writing with a clean Markdown editor.
* Live HTML preview and outline sidebar navigation.
* Focus Mode for the current line, sentence, paragraph, or three lines, plus Hemingway Mode.
* Export via Pandoc, MultiMarkdown, and commonmark, with MathJax equation support.
* Document and session statistics, autosave, and light/dark themes.

## Project Status

ghostwriter is developed on KDE Invent; the GitHub repository is an official mirror whose GitHub releases are outdated.
