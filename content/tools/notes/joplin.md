# Joplin

{{< tool-info >}}

## Key Features

* End-to-end encryption (E2EE) for secure syncing across devices.
* Web Clipper browser extension (Chrome, Firefox) for saving web pages and screenshots.
* Synchronization with Joplin Cloud, Dropbox, OneDrive, Nextcloud, and other services.
* Plugin and custom theme system with an Extension API for developers.
* Offline-first architecture ensuring all data is always accessible locally.
