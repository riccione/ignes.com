# Obsidian

{{< tool-info >}}

## Key Features

* Bidirectional linking between notes with a powerful graph view.
* Local-first storage using plain Markdown files on disk.
* Massive community plugin ecosystem (1,000+ plugins) and custom themes.
* Works entirely offline with data stored locally in user-controlled vaults.
* Canvas feature for visual brainstorming and knowledge mapping.
