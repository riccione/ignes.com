## Key Features

* Privacy-first, local Markdown notes and long-form writing.
* Citation integration with Zotero, JabRef, and other reference managers.
* Pandoc, LaTeX, and Word template support for exports.
* Zettelkasten support and powerful full-text search.
* Themes, dark mode, custom CSS, snippets, and code highlighting.
